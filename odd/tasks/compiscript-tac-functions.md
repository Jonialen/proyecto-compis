# Compiscript direct-function TAC
Objective: deliver simple global functions, typed direct calls, parameters/returns and real abstract activation-record layouts; recursion and closures remain deferred.
Baseline `9b69c29993370ea5a98e7e55870b0d7f98fc9c76`; integration `feat/compiscript-tac`; child `feat/compiscript-tac-functions`; cached `feature-branch-chain`; forecast 1,100–1,600 authored lines; offline `go test`.

## Specs

- **S1 — Authorized slice.** User: `ok siguele`, accepting `funciones simples + llamadas + parámetros + retornos + diseño del registro de activación`. Implement top-level global function declarations, forward direct calls, explicitly typed integer/float/boolean parameters, scalar results and omitted/null-result procedures usable as statements. Validate all bodies, including uncalled functions. Explicitly reject nested declarations/closures, indirect or aliased calls, bodyless external AST functions, untyped/unsupported signatures and direct/mutual recursion cycles. Preserve existing semantic analysis rather than redefine its accepted language. Remaining Entrega 2 features are not claimed complete.
- **S2 — Calls and values.** Evaluate operands and arguments left to right and exactly once. Preserve earlier symbol/argument values before later calls can mutate globals. Keep caller temporaries live across calls. Return values and arguments use existing scalar compatibility and explicit integer-to-float widening; parameter assignments are invocation-local. Scalar call results can be used in existing expressions, conditions, loops and switch tests. Null-result calls are statement-only in this first slice; bare return, return-null and fallthrough are supported in null-result procedures. No default return value or fake void type. Call graph must be acyclic for this slice.
- **S3 — Binding and initialization.** Resolve actual direct global function identities, not a same-name alias or shadowing variable. Function body uses its existing semantic function scope (whole declaration span) with parameters in that scope, not an invented body block. Local blocks retain their snapshots and initializer activation rules. Respect global declaration-order visibility in each body. Compute direct/transitive global dependencies and conservatively refuse a top-level call before required global bindings have initialized, consistent with the existing no-invented-default policy. Global reads/writes are supported when safe; do not confuse their absence of Captured flags with proof of closure support.
- **S4 — IR and activation records.** Preserve exact old text/JSON for programs without functions/calls. Extend instructions and Program only with optional procedure/call metadata, retaining existing field order/tags. Keep main and procedure instruction tapes distinct, with stable unique procedure identities, ordered parameters, return types and source spans. Provide deterministic abstract-cell layouts for continuation/return address, control link, global access link, optional scalar result, parameters, all function-owned locals/constants and temporaries. Temporary storage is frame-local and type-changing; every invocation has fresh local/temporary storage. Describe cell indexes/sizes explicitly as abstract, not completed target-machine byte offsets, ABI, physical registers or closure environments. No new allocator or fake frame metadata for unimplemented features.
- **S5 — Atomicity and executable proof.** On any frontend/semantic/unsupported-function/layout/call-graph/initialization error, return diagnostics and no partial TAC or procedure list. Observe RED before implementation and GREEN after. Commit bounded call-frame interpreter tests that execute the generated main/procedure tapes with independent invocation storage, copy arguments before calls, read operands before writes, restore continuation/control frames and bound steps/depth. Prove forward/repeated/chained calls, typed parameters, local isolation, explicit/fallthrough/null returns, branches/loops/switch within functions, promotions, global dependencies and side-effect ordering in binary operands, arguments and switch selectors. Preserve source/AST/scope data and deterministic layouts/output. Baseline-compare numeric/conditional/loop/switch text/JSON and legacy analysis exactly. Full suite/build/forced vet run only in isolated offline scratch, then an independent verifier checks item 3.
- **S6 — Delivery and limits.** Document the implemented instruction/call/frame contract and a runnable functions `.cps` example without unsupported print. Keep CLI flags/exit policies and analysis HTTP reports unchanged. Preserve original untracked files, use integration/child delivery, no PR/main merge. Risk item 3: shared IR, binding, expression evaluation and temporary/call contracts. Inherited malformed-for panic stays documented and unchanged; no blanket recovery or claim that every malformed input is covered.
