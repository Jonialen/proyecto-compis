# Compiscript switch TAC
Objective: add ordered boolean switch dispatch without fallthrough, preserving analyzer scopes and refusing unsafe case-only binding reads.
Baseline `dde2167fbe0be2c2b9c552903ca97e4ef6de3f64`; integration `feat/compiscript-tac`; child `feat/compiscript-tac-switch`; cached `feature-branch-chain`; forecast 650–950 authored lines; offline `go test`.

## Specs

- **S1 — Authorized scope and policy.** User: `dale`, accepting `Sigue switch, con sus destinos de break y su interacción con ciclos.` Preserve the governing boolean selector rule and compatible/statically unique cases from `docs/semestre2/entrega1/compliance.md:28` and existing semantics. Switch does not fall through. Do not change semantic policy, AST/frontend, grammar, generated files, dependencies or CLI flags. Foreach, functions/closures, objects/lists, ternaries, general assignment expressions and other currently unsupported constructs stay deferred.
- **S2 — Dispatch.** Evaluate the selector exactly once; test case expressions in source order, stopping at the first match at runtime. Evaluate only tests needed to select a body; default executes only when no case matches. Empty/default-only switches still evaluate the selector. Every selected body implicitly exits the switch, including an empty case; explicit break exits the nearest breakable construct. All source cases/tests/defaults remain statically validated, even when not selected. Reject unsupported or invalid content atomically with no partial TAC.
- **S3 — Transfer context and temporaries.** A switch break must not break its surrounding loop; a break in a nested loop exits that loop. Continue inside one or more switches targets the nearest enclosing loop's existing continue label (for post, while/do condition); a standalone switch cannot legalize continue. Restore frames after nested/consecutive constructs and on failure. Reuse existing instructions, allocator, labels, condition/store/environment and transfer helpers; do not create a second allocator or runtime. Preserve a selector temporary across all dispatch comparisons without overwriting it with comparison results; read operands before destination writes, emit located deterministic instructions and keep temporary pressure bounded.
- **S4 — Selected initialization rule.** User selected `Rechazar lecturas no inicializadas` after the question `¿Cómo querés manejar las variables declaradas dentro de los case?` Preserve the analyzer's shared scope inventory and IDs, not artificial per-case semantic scopes. Initialized scalar declarations can be used within their own selected case. Conservatively require shared bindings initialized before switch; do not assume one case's declaration ran in another case or after switch. Reject case-only bindings on those paths explicitly as a documented TAC capability restriction, even if a stronger optimizer could prove a path. Do not invent defaults, leak compile-time active bindings between cases or alter Analyze reports. Predeclared initialized bindings remain assignable/readable through cases and nested blocks.
- **S5 — Behavior and compatibility proof.** Observe RED before implementation, then GREEN through public Compile and the real CLI. Commit executable tests using the existing bounded reference interpreter: first/middle/no/default match, default-only/empty/empty-case, no fallthrough, selector-once and ordered case trap counts, preserved selector after a nonmatching case, nested switches/loops and continue/break destinations, case/outer bindings, atomic validation of unselected unsupported source, source/AST/scope preservation, deterministic labels and bounded temporaries. Baseline-compare existing numeric/conditional/loop TAC and analysis stdout/stderr/exit exactly. Full tests/build/forced vet run only in isolated offline scratch, followed by independent verification for item 3.
- **S6 — Delivery and limits.** Update TAC documentation and a runnable switch `.cps` example while preserving earlier examples. Reuse integration/child delivery; no PR or main merge. Risk item 3: shared lowering and transfer contracts. The inherited malformed-for panic is unchanged and remains an advisory, not a passed raw trace comparison or claimed fix. This unit does not complete Entrega 2.
